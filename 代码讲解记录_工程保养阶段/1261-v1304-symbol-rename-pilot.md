# 1261 - v1304 符号改名试点:7,491 → 7,458,并证伪"别名法"

## 本版目标与不做什么

优雅收官报告(v1300)把 7.5 → 9 的差距拆成三笔账,其中第二笔是
**7,491 个超预算的符号名**(函数 3,177 / 模块级常量 2,671 /
文件名 1,610 / 类字段 33,上限 40 字符)。本版是这条弧的**试点**:
只做 packet_index v1012-v1014 家族的 **33 个符号**,目的不是清债,
而是**验证四条前置命题**。不做什么:不放量;不碰其他家族;
不动任何产物字节。

## 先证伪一条:别名法行不通

直觉方案是"改名 + 留兼容别名":`OLD_LONG_NAME = new_short_name`。
读一遍 `name_budget.py` 的扫描器就否掉了:它把 `ast.Assign` 的目标
按 `variable`(模块作用域)计入违规。于是别名把一条 `function` 违规
**换成一条 `variable` 违规**,存量纹丝不动;而且换底工具会拒绝
(kind 变了,中性不成立)。

这与去重弧里"包装函数/`functools.partial` 都无法降低 dup 指标"
是同一个陷阱:**兼容层本身也会被指标看见**。真正的出路是
**不留别名**——直接退役旧名、全仓改写引用。之所以敢这么做,是因为
本仓**没有外部消费者**,所谓"API 破坏"的范围就是本仓自身。

## 四条命题的验证结果

| 命题 | 结果 |
|---|---|
| P1 旧名在 src/scripts/tests 中彻底消失 | ✅ 断言通过 |
| P2 **没有任何产物字节改变** | ✅ 见下 |
| P3 存量真的下降、且零新增违规 | ✅ 7,491 → **7,458**,new=0 / resolved=33 |
| P4 家族测试全绿 | ✅ 16/16 |

P2 是本版最重要的证明,做法是**全仓字符串常量多重集对照**:改名前后
扫描 src/scripts/tests 每个文件的全部字符串常量,断言**唯一发生变化的
字符串就是被改名的标识符本身**(它们出现在 `__all__` 里)。这直接证明
了产物文件名的**值**没动——因为改的是常量的**名字**,不是它的**值**。
这也是符号改名比 `_style` 收敛安全得多的根本原因。

## 试点抓到第九类耦合:符号名同时是模块名

全字匹配改写之后,一个测试崩了:
`ModuleNotFoundError: No module named 'scripts.build_packet_v1013'`。
根因:本仓的脚本**以它包装的函数命名**,于是那串 191 字符的历史短语
**既是函数名、也是脚本模块名**。标识符级改写顺手把
`from scripts.<长名> import main` 里的**模块路径**也改了,指向一个
不存在的模块。

这个断裂 **ruff 看不见、mypy 也看不见**——它只在 import 时爆炸,而
那个脚本只被一个测试导入,完全可能拖到很久以后才现形。处置:

1. 修好该 import(顺带指向真实脚本模块,而不是长名 shim);
2. 写全仓扫描,确认**只有这一处**;
3. 把扫描**升级为常驻测试** `test_import_target_resolution_v1304`:
   任何 `minigpt./scripts./tests.` 的点分导入都必须指向真实存在的模块;
4. 修**工具本身**:改写前先把导入语句的模块路径**屏蔽**成占位符,
   改写后还原——放量时不会重演。

## 结论:放量可行,但要带着第 9 类耦合的护栏

试点结论是**可以放量**:机制成立、存量真降、产物零变化。剩余
7,458 里约 5,800 是函数名与常量名,和本试点同型。放量前提是
工具已内化模块路径屏蔽 + 常驻的导入解析守卫。

诚实提醒:1,610 条 `filename` 违规**不在**这条弧的射程内——那需要
模块文件名再短一截(当前 ≤120,预算是 40),属于归一化线的活。

## 工程教训

1. **兼容层会被指标看见**:别名、包装函数、partial——凡是留下痕迹的
   兼容手段,都可能把违规从一种 kind 搬到另一种 kind,而不是消掉它。
   先读度量的实现,再设计方案。
2. **"没有外部消费者"是一种可动用的资产**:它把"API 破坏"降级为
   "全仓改写",从而解锁了唯一能真正降存量的路径。这个前提必须写明,
   因为哪天有了外部消费者,结论就反转。
3. **试点的价值在于抓到一类新耦合,而不是省下的工作量**:33 个符号
   本身微不足道,但第 9 类耦合如果在放量批次里首次出现,代价是
   几百个文件的回滚。

产物:33 符号改名(零别名),14 文件改写;
`test_import_target_resolution_v1304`(全仓导入解析守卫);
name-baseline 真实收缩至 7,458;批量工具已内化模块路径屏蔽。
