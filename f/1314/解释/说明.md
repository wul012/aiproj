# v1314 checkpoint 写入失败保护

正式 checkpoint 只在同目录候选文件完成序列化、flush、fsync、关闭后替换。
普通异常展开时清理本次候选文件；保留旧 checkpoint 和其他调用留下的文件。

## 验证结果

- 旧实现的真实训练保存故障测试失败：正式 checkpoint 被 `incomplete checkpoint` 覆盖。
- 新实现定向 28 项测试通过，包含 12 个故障矩阵子场景、训练失败后重新恢复、受控子进程强杀。
- 全量入口退出码 0：`Ran 3590 tests in 857.589s` / `OK`。
- 覆盖率 89.26%，89,533 / 100,305 行；原门槛 88.98% 不变。新保存模块 17 / 17 行覆盖。
- 临时汇总脚本两次误读测试内部状态；测试本身通过的依据是退出码、终态和覆盖报告，
  不是重新命名失败。该教训已提升为 AGENTS.md 中的结果归属规则。

成功存档的数据格式兼容，不承诺新旧序列化文件的容器字节完全一致。
