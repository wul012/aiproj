# v1319 训练数据绑定

新 checkpoint 增加可选 `data_binding`，记录精确 UTF-8 文本摘要、字符长度和 `train_ratio`。
同词表文本发生变化、或恢复时比例漂移，会在 token split、模型、日志恢复和输出之前拒绝。
相同内容换路径并显式使用新输出目录仍可作为分支；旧 checkpoint 无字段仍兼容。

本版不是数据签名、模型质量证明、tokenizer/optimizer 全配置指纹或跨设备确定性保证。
数据目录的准备顺序和小验证集回退逻辑保持不变，科学实验与历史缓存未改。

## 本地验证

- 最终定向回归：64 项测试，15.663 秒，退出 0；新增 9 个方法、22 组损坏元数据子场景。
- 旧实现红灯：同词表文本变化没有被拒绝；新实现保留相同拒绝与文件字节断言。
- 独立 5 进程、9 项检查通过：只新增一个 checkpoint 键，其余字段精确一致，指标、摘要、采样和
  tokenizer 字节一致；同长度文本变化与比例变化拒绝前没有写入运行文件。
- 新模块严格 mypy 与 lint/format 通过；全部快速 CI 命令的结果见 [机器摘要](data-binding.json)。
- 完整 unittest/覆盖率在同提交 GitHub CI 执行，88.98% 门槛不降低；只有成功后才打 v1319.0.0 标签。

只有缺少字段才属于旧格式，显式 null 不视为兼容开关。CRLF/LF 经现有读取规则变成相同文本时
绑定不变；真实加载内容变化仍会拒绝。更换输出目录不豁免新 checkpoint 的同数据续训约束。
